# 🛡️ Privacy

A VPN can help protect network traffic between your device and the VPN server, particularly on public or otherwise untrusted networks.

**No VPN can guarantee complete anonymity.** Websites, browser fingerprints, cookies, signed-in accounts, device configuration, and third-party services may still identify or track users.

# ❓ FAQ

**Is VeliNet VPN free?**  
VeliNet is distributed as a free VPN client.

**How do I install it?**  
Download the archive, extract it, and run the included `.exe` installer.

**Does a VPN make me completely anonymous?**  
No. A VPN can improve network privacy, but online anonymity depends on additional factors such as browser configuration, accounts, cookies, and the services you use.
